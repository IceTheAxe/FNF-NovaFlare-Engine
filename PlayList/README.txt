PlayList —— 播放器歌单目录
==========================

把音频文件（.ogg / .mp3 / .wav）直接放进任意子文件夹就是一张歌单：
无需任何配置，下次打开播放器时自动出现，并自动回写进该文件夹的 List.json。

每个歌单文件夹里可以选放（全部可省）：
  与音频同名的 .png / .jpg   → 封面（也可放 covers/ 子目录，同名即可）
  与音频同名的 .lrc          → 歌词（标准 LRC 格式；也可放 lyrics/ 子目录。
                                .json 为旧版歌词格式，同样支持）
  List.json                  → 曲目清单：扫描会自动维护（新歌追加进来、
                                文件已删除的条目会被清掉）；手改它可以精修
                                歌名、曲师、BPM、封面/歌词路径、多音轨（sound
                                数组第 2、3 项为分轨，与主音轨同步播放）。

文件名写 "Artist - Title.mp3" 会自动拆出曲师与歌名。
"example" 文件夹是官方示例，可整个删除。

安卓端：本目录位于启动时使用的可写存储目录内（.<应用名>/PlayList/），
与 mods/ 同级，用文件管理器或数据线放入即可。
