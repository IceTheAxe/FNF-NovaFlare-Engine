# NovaFlare Engine 更新公告

**1.2.1-Coldfix　数据版本 3.6　2026-09-25**

## 相比原版 NF 新增的内容

1. **FE Features 设置页** —— 新增一页专门放 FE 专属功能开关，想开哪个开哪个。
2. **打击误差条** —— 显示每一击的时机偏差；线条数量、停留时长、位置、指针样式都能调，也可以直接显示毫秒数。
3. **音符轨引导线** —— 打击区背后的参考线，透明度可调。
4. **渐变时间条** —— 进度条从单色改成渐变。
5. **帧延迟显示** —— 屏幕上实时显示帧延迟（ms）。
6. **自定义 UI 配色** —— UI 元素可以用自定义颜色渲染，不再锁死主题色。
7. **新版暂停菜单** —— FE 风格暂停菜单（侧边栏图标 + 信息面板 + 动画）；设置里可切换 **NF / FE / Psych** 三种暂停菜单样式。
8. **中文回退显示** —— 文本里含中文时自动改用文字渲染，不再出现空白或方块。
9. **图形设置独立成组** —— TPS / FPS、渲染线程、画质、抗锯齿、Shader、GPU 缓存、Shader 自动转换等集中到「图形」页。
10. **Win8 风格设置面板** —— 贴右侧滑入的设置面板，Gameplay Changers 已接入。

## 本次修复

1. 恢复 Haxe 层报错（你喜爱的 😱 回来了）。
2. 修复 Android 15/16+ 无法运行 —— NDK 从 r27d 换成 r28c（16 KB 页对齐）。
3. 包名换为 `com.novaFrozen`（或者叫 闪耀寒霜）。
4. 修复了更改输入类型时，游戏必定清空存档的问题。
5. 将 ExtraKeys 的 NoteColor 合并到 `.sol` 里。
6. 移动端存储目录新增 `.NovaFrozen` / `.FrozenEngine` —— 后者可与移动版 Frozen Engine 共用数据文件夹。

## 升级须知

- **无法覆盖安装**：包名已变更，你可以同时安装此改版 NF 和原 NF，且设置不互通。  
  外部存储目录 `/sdcard/.NovaFlare-Engine/` 不受影响。
- **应用显示名变更**：`NovaFlare Engine` → `NovaFlare-Engine`。
