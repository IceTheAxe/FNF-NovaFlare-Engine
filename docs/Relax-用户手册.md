# Relax 放松模式 · 用户手册

> 适用版本：FNF-NovaFlare-Engine（`source/substates/RelaxSubState.hx`，已恢复 Circle 主题 + 旋转唱片）
> 面向：想**用**这个功能的人。想看它怎么修的、性能问题在哪，看 `docs/RelaxSubState-Restore-And-Optimization.md`。

---

## 1. 这是什么

主菜单闲置一段时间后自动弹出的**音乐播放器子状态**：按歌单顺序放歌，屏幕中间转着唱片、外围跟着音乐跳频谱，右上角能拉出歌单和设置。

它不进入游戏谱面、不计分、不影响存档，本质上是一个"带背景动画的歌单播放器"。

---

## 2. 进入与退出

| 操作 | 方式 |
|---|---|
| 自动进入 | 设置 → **FE 特色功能** → 「闲置自动进入 Relax（分钟，0 = 关闭）」，设成大于 0 的分钟数后，主菜单/Freeplay 无输入闲置到时间即自动打开 |
| 手动进入（调试） | 主菜单按 **R** |
| 退出 | **ESC**（手柄 BACK），会恢复主菜单 BGM 并保存设置 |

两个前提：

- 必须至少存在一个有效歌单。一个歌单都没有时，闲置计时到点也会跳过，按 R 也没反应（防止弹出空播放器）。
- 编译时要有 `RELAX_ALLOWED`。`Project.xml` 里已对 `desktop || mobile` 打开，正常构建不用管。

---

## 3. 界面分区

从后往前一共 8 层相机，改主题后视觉差异主要来自这里：

| 区域 | 位置 | 说明 |
|---|---|---|
| 背景层 | 全屏 | 歌单里 `background` 指定的图，放大 1.1 倍，会跟随鼠标做轻微视差位移；Circle 主题下被圆形遮罩裁掉 |
| 唱片层 | 屏幕中央 | `record` 指定的图，等比缩放到直径 300px 的圆形；`enableRecordRotation` 打开时以 20°/秒匀速旋转 |
| 频谱层 | 中央 / 底部 | Circle = 环形频谱；Straight = 底部直条频谱；None = 不画 |
| 粒子层 | 全屏 | 实心三角粒子，自下往上飘，振幅越大既发得越快也升得越快 |
| 文字层 | 屏幕中央 | 歌名（48px）+ 作者（32px），随节拍轻微放大；Circle 主题下同样被圆形遮罩裁切 |
| 歌词层 | 屏幕顶部 | 按时间轴滚动的歌词，语言字体由歌词文件指定 |
| 顶栏 | 屏幕最上方 | 梯形面板，鼠标移到屏幕顶部约 50px 时浮现，含三个图标按钮 |
| 控制条 | 屏幕下方 | 左（上一首）/ 中（播放·暂停 + 当前时长）/ 右（下一首） |
| 进度条 | **按钮块上方** | 细长条，可拖动跳转。鼠标移上去滑块才会显形；判定区在细条上下各放宽 10px，所以不用精确压线 |
| 歌单窗 | 左侧滑出 | Win8 开始屏幕式的磁贴墙，占屏宽 62%，详情见第 6 节 |
| 设置面板 | 右侧滑出 | Win8 设置浮出层，占屏宽 34%，详情见第 5 节 |

## 4. 操作一览

| 动作 | 键盘 / 手柄 | 鼠标 |
|---|---|---|
| 上一首 | `←` | 点控制条左键 |
| 下一首 | `→` | 点控制条右键 |
| 播放 / 暂停 | — | 点控制条中键 |
| 跳到任意位置 | — | 拖动屏幕最底部的进度条（拖动时松手才生效） |
| 打开歌单窗口 | — | 顶栏第 1 个图标（歌单），面板从左滑入；再点一次或按 `ESC` / 右键收起 |
| 打开设置窗口 | — | 顶栏第 2 个图标（齿轮），Win8 浮出层从右滑入；点面板外、按 `ESC` 或右键收起 |
| 歌单：进入 / 播放 | `←→↑↓` 选磁贴，`Enter` 确认 | 单击磁贴。一级是歌单，二级是曲目，二级点曲目直接播 |
| 歌单：返回上一级 | `ESC` / 右键 | 标题栏左上角的 `‹` |
| 歌单：滚动 | `↑↓` 会跟着选中项滚动 | 滚轮，或按住拖动 |
| 锁定（隐藏手机虚拟按键） | — | 顶栏第 3 个图标（锁定） |
| 退出 | `ESC` / BACK | — |

歌单窗和设置面板互斥：开一个会自动收起另一个。歌单窗开着时左右方向键归磁贴用（不再切歌），播放键与进度条照常可用。

## 5. 设置项逐条

设置面板是 Win8 设置浮出层：从右侧滑入，`分组小标题 + 一行一项`，按引擎主色描边。
三种控件对三种选项——开关（Win8 方块滑动开关）、轨道滑块（细轨道 + 方形滑块，点轨道直接跳、按住滑块拖）、下拉（点击展开选项列表）。
鼠标移到哪一行，面板底部说明栏就显示这一项的用途；键盘用 `↑↓` 选行、`←→` 调值、`Enter` 确认、`R` 恢复默认。

中文名与说明来自 `assets/shared/language/Chinese/relax/relax.lang`（缺条目自动回落英文）。

| 选项 | 可选值 | 作用 | 建议 |
|---|---|---|---|
| **播放结束行为** `NextSongs` | Next / Restart / Random | 一首放完后：接着放下一首 / 原地重播 / 随机抽一首 | 默认 Next |
| **唱片旋转** `enableRecordRotation` | 开 / 关 | 开：唱片匀速转；关：唱片会慢慢转回正方向并停住 | 低配可关 |
| **BPM节拍动画** `enableBpmZoom` | 开 / 关 | 按歌曲 BPM 让画面轻微缩放、歌名随拍跳动 | 晕屏者可关 |
| **频谱解析质量** `RelaxAudioDisplayQuality` | 1 – 10 | FFT 分辨率（`fftN = 256 × 该值`）。越高越细腻，越吃 CPU | 桌面 5–8，手机 2–4 |
| **频谱条数** `RelaxAudioNumber` | 1 – 8 | 实际线条数固定 120 条，这个值决定每格合并多少条（条数少 = 单条更粗、更省） | 默认 4 |
| **频谱中间对称** `RelaxAudioSymmetry` | 开 / 关 | 左右镜像，视觉更规整 | 默认开 |
| **视觉主题** `theme` | Circle / Straight / None | Circle：环形频谱 + 圆形遮罩 + 唱片；Straight：底部直条，无唱片；None：只要背景和唱片 | 默认 Circle |
| **歌曲信息位置** `songInfo` | None / Middle / topLeft / downLeft / topRight / downRight | 目前 **只有 None 真正生效**（隐藏歌名与作者），其余四档角位置仍是居中。属于原版遗留未完成项 | 一般保持 Middle |

改完即时生效，不需要重新进状态。切主题时频谱和唱片会重建，会有一次短暂的空场，属正常。关闭面板时会统一回刷一次参数。

> 注意：`theme` 切到 `None` 后没有任何频谱，看起来像"没反应"，其实是按设置不画。

## 6. 自己做歌单

### 6.1 目录结构

```
assets/shared/playlists/<歌单名>/
├── List.json          # 歌单清单（必需）
├── songs/             # 音频（路径自己定，List.json 里写清楚即可）
│   ├── 歌名-Inst.ogg
│   ├── 歌名-Voices-Opponent.ogg
│   └── 歌名-Voices-Player.ogg
├── art/               # 唱片封面
└── lyrics/            # 歌词（可选）
```

歌单名就是文件夹名，进游戏后以**磁贴**形式出现在歌单窗里。仓库自带的 `assets/shared/playlists/demo/` 是可直接跑的示例（6 首官方曲）。

### 6.0 歌单窗长什么样

左侧滑入的磁贴墙（Win8 开始屏幕那种）：

- 磁贴基准 160px、间距 8px，按窗口宽度自动算列数（1280 宽约 4 列）
- **正在播放的那一首占 2×2 大磁贴**，一进二级就会看到它被放大；其余 1×1
- 1×1 只显示封面 + 歌名；2×2 还多一行 `BPM · 作曲家`
- 磁贴下方一条 4px 主色条 = 键盘选中；描边颜色 = 主色（正在播放 / 选中）或白色（悬停）
- 一级是歌单（封面取该歌单第一首的 `record`，没有就取 `background`），点进去二级是曲目
- 进入时磁贴按格序依次淡入；切歌时 2×2 与 1×1 之间是"长大/缩回"的变形

### 6.2 `List.json` 字段

```json
{
    "name": "歌单显示名",
    "list": [
        {
            "name": "歌曲显示名",
            "sound": ["三轨音频路径"],
            "background": ["背景图 key"],
            "record": ["唱片图 key"],
            "lyrics": "lyrics/xxx.json",
            "bpm": 150,
            "writer": "作者"
        }
    ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name`（外层） | 是 | 歌单名，显示在歌单窗口标题 |
| `list[].name` | 是 | 歌名，显示在屏幕中央 |
| `sound` | 是 | 音频路径数组，顺序为 **主旋律 / 对方人声 / 玩家人声**。只给 1 条也能放，但没法和声 |
| `background` | 否 | 背景图，相对 `assets/shared/` 写，如 `"menuBG"` 或 `"playlists/demo/art/xx"` |
| `record` | 否 | 唱片图；留空时会把 `background` 当唱片用 |
| `lyrics` | 否 | 歌词 JSON 路径，相对 `assets/shared/` |
| `bpm` | 是 | 用于节拍动画；填错不会崩，只是不跟拍 |
| `writer` | 否 | 作者名，留空显示 Unknown |

两条容易踩的路径规则：

- **音频**按 `assets/shared/<写的路径>` 找，所以写 `"playlists/demo/songs/x-Inst.ogg"`。
- **图片**最终走 `Paths.image`，实际读的是 `assets/shared/images/<key>.png`。写 `"playlists/demo/art/x"` 没问题，写 `"images/..."` 反而会重复拼一层。图找不到时会静默跳过（不崩，但看不到图）。

### 6.3 唱片封面规格

- 正方形即可，推荐 **300×300**（正好等于圆形遮罩直径），PNG 带透明通道最佳。
- 会被裁成圆形，四角内容看不到，主体尽量居中。
- 同一张图也是歌单窗里的磁贴封面（磁贴是方的，靠等比缩放铺满，非正方形素材会留边）。

仓库 `demo` 歌单的 6 张封面是用官方 `storymenu/titles/weekN.png` 周封面套在深色圆盘上生成的（见 `art/` 目录），可以直接替换成自己的图。

### 6.4 歌词格式

```json
{
    "font": "assets/fonts/Lang-ZH.ttf",
    "lyrics": [
        [28900, "时间戳单位是毫秒"],
        [33720, "第二条"]
    ]
}
```

- `font` 是字体路径，中日文歌词记得换成对应字体，否则显示方块。
- `lyrics` 按毫秒升序排；播放时取"最后一个 ≤ 当前时间"的条目。

## 7. 常见问题

**进不去 / 按 R 没反应**
检查 `assets/shared/playlists/` 下是否至少有一个含 `List.json` 的子目录；只有文件夹没有 `List.json` 不算。

**歌单窗口是空的**
`List.json` 解析失败或 `list` 为空。JSON 不要带注释，字段名大小写敏感。

**有声音没画面 / 一片黑**
多半是背景图或唱片图找不到（会静默跳过）。把 `background`、`record` 的值和 `assets/shared/images/` 下的实际文件名核对一遍。

**封面是方的、四角露出来**
说明当前是 Straight 或 None 主题（没有圆形遮罩）。要么换回 Circle，要么把封面本身做成圆形透明 PNG。

**切歌卡一下**
三轨音频是整段解码的，切歌瞬间会有解码尖峰。想缓解：把 `频谱解析质量` 调低；后续版本可改为流式加载（见性能文档）。

**画面太糊 / 太亮**
`视觉主题 = None` 会去掉频谱和遮罩；嫌唱片太亮可以把封面图本身压暗。

**手机端虚拟按键挡住界面**
点顶栏第 3 个"锁定"图标即可隐藏。

**看不到粒子 / 画面很干净**
已经修好了（旧版粒子发射率会被自己乘成 0，永远不会发射）。如果关掉了 `BPM节拍动画` 也还是没有任何三角在飘，那是振幅一直很低——安静段落发射很稀疏是正常的。

## 8. 已知限制

- `songInfo` 的四角位置未实现，只能隐藏或居中。
- 歌单窗是"认封面找歌"的形态：曲目多时 1×1 磁贴上的歌名会比较小，建议配合方向键 + 磁贴下方的选中条。
- 设置面板按滑鼠操作设计：轨道滑块要靠拖动，键盘只能 `←→` 一档一档调。
- 歌词/歌名文字在 Circle 主题下会被圆形遮罩裁切，长歌名要自己控制长度。
- 只支持 ogg（`Paths.returnSound` 走 Flixel 原生解码），不要指望 mp3。
