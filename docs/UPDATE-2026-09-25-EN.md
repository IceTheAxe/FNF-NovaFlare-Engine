# NovaFlare Engine Update Notes

**1.2.1-Coldfix　Data version 3.6　2026-09-25**

## New in this build (vs. upstream NF)

1. **FE Features page** — a dedicated settings page for FE-exclusive toggles; enable whichever ones you want.
2. **Hit error bar** — shows the timing error of every hit; line count, hold time, position and pointer style are all adjustable, and it can display the raw milliseconds.
3. **Strum guide lines** — reference lines behind the strumline, with adjustable opacity.
4. **Gradient time bar** — the progress bar is drawn as a gradient instead of a flat colour.
5. **Frame delay readout** — shows real-time frame delay (ms) on screen.
6. **Custom UI colours** — UI elements can be rendered in custom colours instead of a fixed theme palette.
7. **New pause menu** — an FE-style pause menu (sidebar icons + info panel + animations), with a setting to switch between the **NF / FE / Psych** pause menu styles.
8. **Chinese text fallback** — text containing Chinese is rendered as real text instead of showing blanks or boxes.
9. **Graphics settings moved to their own page** — TPS / FPS, render thread, quality, antialiasing, shaders, GPU cache and shader auto-conversion now live under "Graphics".
10. **Win8-style settings panel** — a settings panel that slides in from the right; Gameplay Changers already uses it.

## Fixes

1. Restored Haxe-layer error reporting (the 😱 you know and love is back).
2. Fixed NovaFlare failing to launch on Android 15/16+ — the linking NDK was moved from r27d to r28c (16 KB page alignment).
3. Package name changed to `com.novaFrozen` (a.k.a. 闪耀寒霜).
4. Fixed a bug where changing the input type would always wipe the save file.
5. ExtraKeys note colors are now stored inside the `.sol` save file instead of a separate JSON.
6. Added `.NovaFrozen` / `.FrozenEngine` as mobile storage directory options — the latter shares its data folder with Frozen Engine Mobile.

## Before you upgrade

- **This build cannot be installed as an update.** The package name changed, so you can keep this build and the original NovaFlare installed side by side — their settings do not carry over.  
  The external storage directory `/sdcard/.NovaFlare-Engine/` is unaffected.
- **App display name changed:** `NovaFlare Engine` → `NovaFlare-Engine`.
